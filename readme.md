# 📚 Projet Design Patterns - INF4067

## 📋 Description
Implémentation complète des principes SOLID et des design patterns étudiés dans le cours INF4067. Chaque pattern est illustré avec du code Java, diagrammes UML et exemples.

##  📖 Patterns Implémentés
🔷 Principes SOLID

    SRP : Single Responsibility Principle - Chaque classe a une seule responsabilité

    OCP : Open/Closed Principle - Ouvert à l'extension, fermé à la modification

    LSP : Liskov Substitution Principle - Sous-classes substituables

    ISP : Interface Segregation Principle - Interfaces spécifiques

    DIP : Dependency Inversion Principle - Dépendre des abstractions

 🏭 Patterns de Construction 
1. Singleton
2. Factory Method 
3. Abstract Factory 
4. Builder
5. Prototype 

🧠 Patterns de Comportement
1. Template Method
2. Strategy
